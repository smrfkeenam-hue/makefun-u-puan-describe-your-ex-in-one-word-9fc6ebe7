Entry for the [Describe Your Ex in One Word](https://make.fun/c/u-puan-describe-your-ex-in-one-word-9fc6ebe7) bounty on make.fun.

The entry is a single word: **Unsubscribe**. The whole relationship was a
newsletter I never signed up for — so the verdict is what anyone does with
that mail.

`main.py` (Python 3, standard library only) writes the word to
`/output/entry.txt` with no trailing newline.
